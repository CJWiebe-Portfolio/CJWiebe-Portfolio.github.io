Gameplay

Change the Game Difficulty

Change the difficulty level of the game which effects stats within the game; such as mini-games, damages, resource requirements and expenditures.

Game length

Change the game length to increase the total amount of days a run has. The longer a run will give the horde more nights to grow, and give you more nights to run out of supplies. The story will continue to play scripted events regardless of the game length.

Mini-games

If this option is activated you will not be prompted to play the mini-games.

Write a game-seed to generate the same game world each time, allowing for events to repeat in the same order. Or, leave blank for a random seed each game.

Display and accessibility

Text size

Change the size of the text displayed in the game. A larger text size may be easier to read, while a smaller text size may allow more information to fit on the screen.

Adjust the speed at which text is displayed in the game. A higher value will make the text appear faster, while a lower value will slow it down.
